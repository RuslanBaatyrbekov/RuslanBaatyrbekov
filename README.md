**👨‍💻 About Me**

I am a Full-Stack Software Engineer with **3.5 years of commercial experience** architecting scalable web applications and enterprise backends. I bridge the gap between high-level web infrastructure and low-level hardware by designing complete pipelines—from ESP32 edge devices to robust Laravel-driven APIs and Vue.js dashboards. 

I specialize in clean architecture, relational database design, and integrating external services (payment gateways, 1C ERP, AI models). Currently, I am expanding my cloud architecture expertise to build secure IIoT (Industrial IoT) solutions.

- 🚀 **Currently working on:** A smart automated Job Application Tracker leveraging the **Gemini API** via IMAP, and an ESP32-S3 E-Ink smart clock with custom embedded audio.
- 🛠 **Current technical focus:** AWS Cloud Architecture (IoT Core), Laravel Microservices, MQTT/Edge Computing, and hardware retrofitting.
- 🎓 **Education:** Master's degree in Automation and Management in Technical Systems (Kyrgyz State Technical University).
- 📜 **Certifications:** "Introduction to Modern AI" (Cisco Networking Academy).
- 🚗 **Off-screen:** Restoring classic German cars (Mercedes-Benz W124) with custom 3D-printed electronics, and creating tech/automotive content on YouTube/Instagram.
